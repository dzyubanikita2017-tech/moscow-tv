# Moscow TV — минималистичная Android TV оболочка

Первый прототип домашнего экрана в тёмном минималистичном стиле, вдохновлённом простотой Apple TV (не использует логотипы или ресурсы Apple).

## Что уже есть
- тёмный фон и минималистичная композиция;
- часы и дата на русском языке (берутся из системного времени телевизора);
- текущая погода Москвы через Open-Meteo без API-ключа;
- карточки для YouTube, VK Видео, Zona, V2RayTun и Google Play;
- навигация пультом через фокусируемые карточки;
- приложение не удаляет и не отключает системные пакеты.

## Важно
Это исходный Android Studio проект, не готовый APK. Его нужно собрать в Android Studio на компьютере с Android SDK. В этом окружении сборка APK не выполнялась. Пакеты некоторых приложений могут отличаться на конкретном Philips; если карточка сообщает, что приложение не найдено, пакет нужно уточнить через ADB.

## Сборка
1. Установить Android Studio и Android SDK Platform 35.
2. Открыть эту папку как проект.
3. Дождаться синхронизации Gradle.
4. Выбрать Build > Build APK(s).
5. Установить полученный APK на телевизор через ADB Explorer.

## Важные ограничения первого прототипа
- Системный лаунчер не отключается автоматически.
- Для полноценной замены домашнего экрана Android TV могут потребоваться дополнительные настройки HOME/default launcher; сначала проверьте обычный запуск приложения.
- Погода требует интернет-соединения.
- Прототип ориентирован на простоту, без фоновых рекомендаций и тяжёлых анимаций.
